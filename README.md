# My-searcher
a16zの発信（記事・ニュースレター）と行動（ポートフォリオ）、工学・科学メディアを自動で収集・考察し、週次のWebサイトとメール通知で届ける個人用の情報収集システム「a16z Digest」を作る。目的は、世の中の需要や情勢を把握し、今後伸びる技術・企業を先取りすること。関心トラック（アクチュエータ、パワエレ、Physical AI、AIインフラ、エッジAI、製造、物理・科学、AI×化学）ごとに記事を整理し、企業の動きやキーワードの変化、予測の答え合わせまで追う。a16zはポジショントークを含む前提で、工学メディアで裏取りする。本実装はClaude Codeで行い、ここでは設計・機能追加・考察の相談をする。
